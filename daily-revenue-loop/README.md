# Daily Caesar self-annealing revenue loop

Prototype scaffold for a weekday operating loop that turns visible CRM/business state into founder-leverage moves.

## Loop contract

1. Inspect current clients, quiet leads, proposals, build state, approvals, and recent correspondence.
2. Generate revenue moves: follow-ups, authority assets, pricing/productisation ideas, and founder bottleneck removals.
3. Draft or propose only. External/public/client-facing actions stay approval-gated.
4. Surface only strategic decisions, uncomfortable truths, and true blockers.

This branch defines the first deterministic loop planner for review.
