# Workflow Blueprint API (prototype)

Turn a plain-language description of a workflow into a structured, reusable **blueprint**
— the building block other Synergaise services compose. Phase-1 scaffold: a deterministic
blueprint builder over a typed shape. No network, no LLM yet — that lands in a later layer.

Idea origin: founder_mention. Tracked in the `ideas` table; built via the gated rail.
